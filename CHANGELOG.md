# Changelog of `sf-symbols-svg`

## 8.0.0-beta.123 - 2026-06-24

- Add SF Symbols 8 symbols (7151 total, 257 new compared to 7.2), from the
  SF Symbols 8 app (build 123)
- Support `symbols.txt` exported with one glyph per line (newer SF Symbols app
  export format), in addition to the older continuous format

> [!NOTE]
> This is a beta release based on the SF Symbols 8 beta.
> Apple may add or rename symbols before the final release, so a stable `8.0.0` will follow once SF Symbols 8 ships.
> Install it with `npm install sf-symbols-svg@beta`.
